# Feature Request

> Record the **problem**, not the feature. A merchant asking for a button is describing a job they
> cannot finish — capture the job.
>
> Never promise anything. "I'll write that down" is the correct response, every time.

## Priority guide

| Priority         | Test                                                              |
| ---------------- | ----------------------------------------------------------------- |
| **Blocker**      | A merchant has stopped using Vyora, or will, without it           |
| **Strong**       | Multiple merchants hit it repeatedly and work around it           |
| **Nice**         | Asked once, no workaround needed                                  |
| **Out of scope** | Serves none of the three pillars, or is on the permanent-out list |

**Permanently out**, whoever asks: lending, interest on udhaar, BNPL, automatic dunning, sending
messages on the merchant's behalf, sharing data with anyone, multi-user accounts.

If a merchant asks for one of these, record it — and note _why_ they asked. The reason is usually a
real problem with a different, acceptable solution.
