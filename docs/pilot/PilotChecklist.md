# Pilot Checklist

> Tick every box. An unticked box is a merchant you are not ready to onboard.

---

## A. Before the pilot — once, on your own phone

- [ ] Deployment complete and `DeploymentChecklist.md` fully ticked
- [ ] **Settings → Version** reads **1.0.0-rc1**
- [ ] Both known blockers closed (see `KnownIssues.md` **C1** and **C2**) or consciously accepted
- [ ] You have read `FounderPilotPlaybook.md`
- [ ] `MerchantQuickStart.md` printed or ready to send on WhatsApp
- [ ] A blank `BugReport.md` and `FeatureRequest.md` ready per merchant
- [ ] `PilotMetrics.md` sheet created with one column per merchant

## B. Per merchant — onboarding day

Do all of this **on the merchant's own phone**, with them holding it.

**Install**

- [ ] `esytol.com/vyora` opens in their browser
- [ ] Install banner appears → installed
- [ ] The icon on the home screen is the **Vyora** mark, not esytol's _(see KnownIssues C2)_
- [ ] Opening from the icon shows **no browser address bar**
- [ ] **Settings → App installed: Yes**

**Capture**

- [ ] One real credit recorded, with a due-date chip tapped
- [ ] The due preview showed a real date and weekday
- [ ] One real payment recorded
- [ ] Home shows the correct _You'll get_ figure — **merchant confirms it matches their notebook**

**Recovery**

- [ ] **Chase** lists the right people
- [ ] The merchant agrees with who is at the top
- [ ] A phone number is tappable and dials
- [ ] **What to say** produces a message _the merchant is willing to send_
- [ ] **Share** opens their own WhatsApp/share sheet

**Closing**

- [ ] **More → Closing** opens and today's figures match what they just entered
- [ ] **Finish today** completes and appears in closing history

**Settings and backup**

- [ ] Data-safety card is honest about their current state
- [ ] **Export ledger** downloads a file
- [ ] **The file is sent to the merchant's own WhatsApp** — do not leave without this
- [ ] Business name entered (it appears in reminder messages)
- [ ] Backup reminder set to **Weekly**

**Offline**

- [ ] Airplane mode on → close app → reopen from icon
- [ ] **The app opens and their entries are intact**
- [ ] One credit recorded while offline, successfully
- [ ] Airplane mode off

**Diagnostics**

- [ ] Founder Mode opens (tap "Alpha" ×5)
- [ ] **Integrity: all checks passed**
- [ ] Baseline numbers recorded in `PilotMetrics.md`

**Handover**

- [ ] Merchant has `MerchantQuickStart.md`
- [ ] Merchant knows to export weekly
- [ ] Merchant has your number and knows to message about anything odd
- [ ] You have their device model, browser and OS version written down

## C. During the pilot

**Daily**

- [ ] Checked in with every merchant
- [ ] Logged any bug the same day
- [ ] Noted anyone who recorded nothing

**Weekly**

- [ ] Founder Mode numbers captured per merchant
- [ ] Integrity checks passed on every phone
- [ ] Every merchant has exported within seven days
- [ ] One interview completed
- [ ] `KnownIssues.md` re-ranked

## D. After the pilot — per merchant

- [ ] **Final export taken and stored by you** — do this first, before anything else
- [ ] Closing interview completed (`InterviewGuide.md`)
- [ ] All bugs transferred to `BugReport.md`
- [ ] All requests transferred to `FeatureRequest.md`
- [ ] Final metrics recorded
- [ ] Merchant told plainly what happens next
- [ ] If they are stopping: notebook restored, data exported, and they know how to get it back

## E. After the pilot — overall

- [ ] All exports archived off the merchants' phones
- [ ] `PilotMetrics.md` complete for every merchant, every week
- [ ] Findings written up: what was used, what was ignored, what broke
- [ ] Go/No-Go on continuing, with evidence
